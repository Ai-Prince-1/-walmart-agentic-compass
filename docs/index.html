How it works

Three layers. The page you're reading is the showcase; the agent itself runs on a small server that wakes up only when someone uses it.

Knowledge

What the agents know

A searchable index of the Google × Kaggle agent-engineering whitepapers and a retail strategy brief. Every answer cites its source and page.

Reasoning

Where the thinking happens

Python on Google's Agent Development Kit, with Gemini 2.5 Flash-Lite as the model. A router hands each question to a specialist, and tools are served over the Model Context Protocol (MCP).

Interface

What people see

A chat page served by the same app on Google Cloud Run. It scales to zero when idle and is capped at one instance. This showcase page is hosted free on GitHub Pages.

The API key lives in Google Secret Manager, never in the code or in your browser. A rate limit, a daily request cap and an optional demo passcode keep the free quota safe.

The agents

Each specialist is defined by a versioned skill file with examples of when it should and shouldn't take a question.

Orchestrator

Reads the question and routes it to the right specialist. It never answers from its own head, which keeps every reply grounded and attributable.

Curriculum mentor

Explains agent-engineering concepts from the course material, with citations.

Strategy advisor

Maps a use case to business moats and returns a 90-day plan.

Governance auditor

Runs the readiness scorecard above and lists the approvals required.

Guardrails by design

The rules are enforced by how the system is built, not by asking the model to behave.

  • No write accessThe agents have search and scoring tools only. There is nothing they could change even if told to.
  • Fail closedAn unknown permission level is scored as the riskiest one.
  • Input tripwirePrompt-injection attempts and requests for internal data are blocked before reaching the model.
  • Cost circuit breakerPer-visitor limits and a daily cap stop runaway spend.
  • Tested on every change13 automated tests that run without an API key, plus trajectory evals with a position-swapped LLM judge.
  • Checked monthlyA scheduled job wakes the live agent and confirms the key still works, so a demo never starts with a surprise.
